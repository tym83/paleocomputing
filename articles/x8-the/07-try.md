# Как это потрогать

Нужны только компилятор C и Python:

```sh
git clone https://github.com/tym83/paleocomputing
cd paleocomputing/impl/x8-the
make -C emu              # X8 с CHARON
tests/x8stest.sh         # тестовая программа 1971 года: 375 тестов
tests/the.sh             # THE: загрузка, три программы, консоль и печать
labs/check.sh 01         # то же самое как лабораторная
```

Тестовая программа скачивается со страницы Дика Грюне и в репозитории не лежит: это не мой текст. Сама THE собирается ассемблером из `the/the.elan` в перфоленту формата начальной загрузки, и эмулятор запускает её так, как запускали машину: LS, потом IP.

Лабораторных шесть, и проверяет их `labs/check.sh`. В них есть опыты из прошлой главы: меньше страниц памяти, сломанный уровень, другой квант времени. Есть ответ оператора с другим числом и прогон тестовой программы X8. Время в эмуляторе виртуальное, поэтому вывод можно сравнивать с чужим посимвольно, вплоть до миллисекунд в метках консоли.

В браузере этого пока нет, как нет и машины X8 в Kubernetes. Обе вещи будут, как было с машиной Оберона в прошлых частях серии: эмулятор написан на C и собирается в WebAssembly без переделок.
