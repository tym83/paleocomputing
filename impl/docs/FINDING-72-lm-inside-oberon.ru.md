# Находка 72. Языковая модель внутри Оберона: текст совпал с эталоном до байта

Символьная языковая модель работает внутри системы Оберон на RTL Вирта —
и в пакетном режиме Norebo, и в настоящей системе с окнами, 1 МБ памяти и
диском. Модуль собирает компилятор самой системы. Напечатанный текст
побайтово равен тексту, который посчитал эталон на хосте в арифметике RISC5.

```
alice was one thought all the tell you spo
```

(затравка `alice was `, зерно 1, 32 символа; выход модели на 43 тыс.
параметров, обученной на «Алисе» — «похоже на английский», не больше.)

## Что это за модель

| | |
|---|---|
| архитектура | MLP Бенжио: 8 символов контекста → вложения 16 → 256 (ReLU) → 36 логитов |
| параметров | 42 852, веса fp32 — 171 572 Б с заголовком (`lm/LM.Weights`) |
| текст | Lewis Carroll, *Alice's Adventures in Wonderland*, Project Gutenberg #11, общественное достояние; служебные шапка и подвал PG удалены (`lm/alice.txt`) |
| обучение | numpy, зерно 1, 12 эпох, десятки секунд на ноутбуке; потери 1.24 / 1.57 нат/символ (обучение / отложенные 10%) — `lm/weights.json` |
| выборка | softmax с температурой 0.8, `exp` по схеме `Math.exp` Вирта, свой ГПСЧ (LCG) |

Размеры выбраны под вопрос выпуска, а не под качество текста: символ стоит
~42 тыс. умножений с накоплением, и почти все они — в двух циклах
скалярного произведения. Больше ничего в модели нет.

## Почему эталон точен до бита

Сравнивать с numpy бессмысленно: плавающая точка Вирта — не IEEE
(находка 50). Эталон `lm/ref.py` повторяет каждую операцию модуля в том
же порядке и считает её функциями `risc-fp.c`, уже сверенными с RTL на 1056
случаях. Сравнения — через знак и ноль результата `FSB`, как их делает
кодогенератор; `FLOOR`, `FLT`, `PACK` — теми же битовыми операциями, что
излучает `ORG.Mod`. Константы в модуле заданы битами
(`SYSTEM.VAL(REAL, 3FB8AA3CH)`): десятичную запись переводил бы компилятор
своей арифметикой, и её тоже пришлось бы повторять.

Совпадение проверено на трёх исполнителях одного и того же `LM.rsc`:

| исполнитель | что сверено | результат |
|---|---|---|
| эмулятор Norebo на C | 5 зёрен × 128 символов | побайтово ✅ |
| RTL Вирта (Norebo на Verilator) | 32 символа, зерно 1; и 8 символов | побайтово ✅ |
| RTL с быстрыми умножителями | 32 символа на обоих вариантах | побайтово ✅ (находка 73) |

## Внутри настоящей системы

Пакетный Norebo — не вся правда: у него 8 МБ памяти. Модель обязана
помещаться в машину Вирта, поэтому отдельный прогон — в настоящей системе
на RTL (`tb/soc_tb.cpp`, 1 МБ ОЗУ, SD-карта, экран):

1. `lm/mkdisk.sh` кладёт на копию эталонного образа `LM.Mod`, `LM.Weights`
   и дописывает две строки в `System.Tool`.
2. Сценарий `scripts/lm.src` — два средних щелчка: `ORP.Compile LM.Mod/s`
   (компилирует сама система: `compiling LM new symbol file 892 1856`) и
   `LM.Generate 16 1 "alice was "`.
3. Модуль пишет текст в журнал и в файл `LM.Out`; `lm/outcheck.py` снимает
   файл с образа и сверяет с эталоном: **совпало** (`alice was one thought all `).

Бюджет памяти (по исходникам, `13-episode-lm-on-risc5.md`): куча
`80000H…0E7EF0H` = 425 712 Б; запись с весами — 171 408 Б, одним `NEW` на
старте, это 40% кучи. Код модуля 892 слова, глобальные — 1856 Б.

Первая попытка положить на диск готовый `LM.rsc` из Norebo провалилась с
`Call error: LM imports Files with bad key`: объектный файл помнит ключи
символьных файлов того окружения, где его собрали. Поэтому компиляция —
только внутри системы, и это заодно честнее.

## Чего это не показывает

* Такты в настоящей системе не снимались: у `soc_tb` нет окна замера, а
  между символами работает оконная система. Числа тактов — из Norebo на
  RTL (находка 74), там исполняется тот же код шага модели.
* Видео-DMA в стенде не подключён (находка 17): на плате, где видеоконтроллер
  крадёт такты, генерация будет медленнее.

## Как повторить

```
cd impl
make lm-check     # веса = манифест; эмулятор против эталона, 3 зерна × 64 символа
make lm           # то же на RTL Вирта, 2 зерна × 16 символов
make lm-system    # в настоящей системе на RTL, ~4 минуты
python3 lm/train.py   # переобучить (побитово — только на той же машине, см. скрипт)
```
