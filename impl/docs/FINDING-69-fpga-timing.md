# Находка 69. Задержки проводов: ядро на настоящей ткани ПЛИС

На странице проекта стояла оговорка: «на живой плате не запускали; синтез
прогнан, но задержки проводов в расчёт не входят». Плату ещё не купили, но
главное, ради чего она нужна, можно получить без неё: развести ядро RISC5 на
настоящей ткани ПЛИС открытыми инструментами и снять статический временной
анализ — с проводами.

## Как

Кристалл — Lattice ECP5 LFE5U-85F, как на плате ULX3S (под неё целиком
открытый поток и существующий порт Оберона — EMARD, `ulx3s_v20_top.v`). Поток
yosys → nextpnr-ecp5 в образе Debian trixie по дайджесту, версии пакетов
прибиты по архитектуре (`impl/fpga/Dockerfile`). Две обёртки:

* **core** — только ядро; входы и выходы через регистры;
* **soc** — ядро + загрузочное ПЗУ на инвертированном такте + мультиплексор
  кода, как в `RISC5Top.v`; внешняя SRAM заменена регистрами.

Цель — 25 МГц: столько даёт исходный дизайн (`RISC5Top.v` делит 50 МГц
пополам), столько же гонит процессор порт для ULX3S. Пять запусков с разными
зёрнами разводки на вариант; CI падает, если хоть один не держит цель.

## Что вышло

Медиана по пяти зёрнам, МГц (CI, amd64; локальный прогон на arm64 — в
`impl/fpga/results.md`, расходится в пределах разброса зёрен):

| вариант | без CHK | с CHK | запас к 25 МГц |
|---|---:|---:|---:|
| core | 47.5 | 48.2 | 1.8× |
| soc | 33.0 | 33.7 | 1.26–1.29× |

* **25 МГц держатся с запасом** во всех двадцати разводках.
* **CHK частоты не трогает.** Разница медиан меньше разброса зёрен внутри
  одного варианта, и знак её разный в CI и локально.
* **Провода — большая часть задержки.** На критическом пути ядра (сумматор
  плавающей точки, `fpaddx`) провода — 12.9 нс из 20.8, в soc (от выхода
  регистрового файла к адресу памяти, полтакта на инвертированном фронте) —
  11.2 из 14.2. Оговорка на странице была по делу: без проводов предельная
  частота вышла бы в 2.6 раза выше для ядра и в 4.7 раза — для soc.
* Ресурсы: около 2.9 тыс. LUT4 и 0.6 тыс. триггеров — несколько процентов
  LFE5U-85F.

## Чего это не показывает

* Это временной анализ, а не работа на плате: нет SDRAM (на ULX3S она вместо
  SRAM, порт EMARD её адаптирует), нет видео, нет измеренных тактов на
  железе. Такты на команду по-прежнему из модели RTL.
* Частота ПЛИС — не частота кристалла ASIC; для ASIC был отдельный синтез
  (находка 3), и провода там тоже не учитывались.
