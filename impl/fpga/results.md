Выводы — в [находке 69](../docs/FINDING-69-fpga-timing.md).

Прогон: colima на Apple Silicon, linux/arm64, 2 ядра, без эмуляции. На
x86-64 в CI те же версии пакетов; тайминговая модель nextpnr от архитектуры
хоста не зависит, но размещение с плавающей точкой может разойтись в
последнем знаке — сверять по CI.

## Цель

- Кристалл **LFE5U-85F-6BG381C** (ULX3S 85F), скоростной класс 6:
  `nextpnr-ecp5 --85k --package CABGA381 --speed 6`.
- Целевая частота **25 МГц** — частота исходного дизайна. Проверено по
  исходнику: `RISC5Top.v` делит вход `CLK50M` пополам
  (`always @ (posedge CLK50M) clk <= ~clk`), а миллисекундный таймер
  считает 25 000 тактов (`limit = (cnt0 == 24999)`), то есть система Вирта
  рассчитана ровно на 25 МГц. Порт EMARD для ULX3S тоже гонит процессор на
  25 МГц (`clk_cpu`, `hdl/top/ulx3s_v20_top.v`).
- Зёрна размещения 1…5 (`--seed`), по каждому своя трассировка.

## Обёртки

- **soc** — ядро + загрузочное ПЗУ на инвертированном такте + мультиплексор
  кода, как на кристалле в `RISC5Top.v`. Внешняя SRAM заменена регистрами.
- **core** — только ядро; код, данные, rst, irq, stallX из регистров, выходы
  в регистры.

**Ни одна из них не система.** Путь через внешнюю память (адрес → выводы →
SRAM → выводы → ядро в одном такте) без платы не измерить. См. README.md.

## fmax, МГц

| обёртка / ядро | seed 1 | seed 2 | seed 3 | seed 4 | seed 5 | min | медиана | max | запас к 25 МГц (по min) |
|---|---|---|---|---|---|---|---|---|---|
| soc / base | 33.26 | 33.60 | 35.62 | 33.97 | 36.35 | 33.26 | 33.97 | 36.35 | 1.33× |
| soc / chk  | 37.29 | 36.08 | 37.77 | 36.89 | 36.02 | 36.02 | 36.89 | 37.77 | 1.44× |
| core / base | 47.29 | 45.76 | 48.91 | 46.60 | 47.07 | 45.76 | 47.07 | 48.91 | 1.83× |
| core / chk  | 45.46 | 45.56 | 44.37 | 45.21 | 46.25 | 44.37 | 45.46 | 46.25 | 1.77× |

Все 20 прогонов держат 25 МГц. Для soc частота считается уже с учётом того,
что путь в ПЗУ полутактовый: nextpnr пересчитывает его в полный период.

**Влияние CHK:**

| обёртка | медиана base | медиана chk | Δ медиан | разброс зёрен внутри base |
|---|---|---|---|---|
| soc  | 33.97 | 36.89 | **+8.6 %** (CHK быстрее) | 33.26…36.35 (9.3 %) |
| core | 47.07 | 45.46 | **−3.4 %** (CHK медленнее) | 45.76…48.91 (6.9 %) |

Знак дельты меняется при смене обёртки, и в обоих случаях диапазоны зёрен
перекрываются (soc: 36.02…36.35, core: 45.76…46.25). Ни в одном из 20
прогонов компаратор CHK не лежит на критическом пути.

## Критический путь

Разбивка — по отчёту nextpnr (`--report`), зерно 1; остальные зёрна
начинаются и кончаются в тех же блоках.

| обёртка / ядро | фронты | задержка | логика | провода | доля проводов |
|---|---|---|---|---|---|
| soc / base  | posedge → negedge | 15.03 нс | 3.25 | 11.78 | 78 % |
| soc / chk   | posedge → negedge | 13.41 нс | 3.11 | 10.30 | 77 % |
| core / base | posedge → posedge | 21.15 нс | 7.89 | 13.26 | 63 % |
| core / chk  | posedge → posedge | 21.99 нс | 8.02 | 13.97 | 64 % |

- **soc**: регистр команды `IR` → дешифрация операции → сигналы остановки
  умножителя, делителя и блоков плавающей точки (`stallM`, `stallD`,
  `stallF*`) → `stall` → `pcmux` → `adr` → адресный вход блока памяти ПЗУ.
  ПЗУ тактуется `~clk`, поэтому у этого пути **полпериода**: 20 нс при
  25 МГц. Это путь «следующий адрес команды должен успеть к спаду такта».
- **core**: регистр `Sum` сумматора с плавающей точкой → смена знака и
  нормализация (`FPAdder.v`: `s = (Sum[26] ? -Sum : Sum) + 1`, поиск
  старшей единицы, сдвиг) → `fsum` → `aluRes` → `regmux` → флаг нуля
  (`zz = regmux == 0`) → `SPC` (сохранение флагов при входе в прерывание).
  Путь целиком в коде Вирта, CHK его не касается.

## Ресурсы

yosys `synth_ecp5` (`stat`) и nextpnr (упакованные ячейки). Из 83 640 LUT
кристалла занято менее 5 %.

| обёртка / ядро | LUT4 | CCU2C (перенос) | TRELLIS_COMB (nextpnr) | FF | LUTRAM (DPR16X4) | BRAM (DP16KD) | DSP (MULT18X18D) |
|---|---|---|---|---|---|---|---|
| soc / base  | 2948 | 329 | 3872 | 582 | 24 | 1 | 0 |
| soc / chk   | 3001 | 345 | 3961 | 582 | 24 | 1 | 0 |
| core / base | 2908 | 329 | 3832 | 614 | 24 | 0 | 0 |
| core / chk  | 2936 | 345 | 3896 | 614 | 24 | 0 | 0 |

- CHK: **+16 CCU2C** (компаратор `B >= chkLim` на цепочке переноса, 32 бита)
  и **+64…89 TRELLIS_COMB (+1.7…2.3 %)**. Триггеров не добавляет.
- Регистровый файл (три порта чтения, один записи) лёг в LUT-память:
  24 `TRELLIS_DPR16X4` = 8 на порт чтения × 3 копии.
- DSP ноль: умножитель у Вирта последовательный (33 такта, сдвиг и
  сложение), как и делитель. ПЗУ — один блок DP16KD (512 × 32).
- FF обёрток (сдвиговый регистр входов, защёлки выходов) в числа входят;
  у core их на 32 больше из-за входа кода.
