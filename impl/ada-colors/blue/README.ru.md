# BLUE

Язык фирмы SofTech для конкурса DoD-1, восстановленный по спецификации от
15 февраля 1978 года (DTIC ADB950587). BLUE прошёл во второй тур вместе с RED,
GREEN и YELLOW и выбыл весной 1978-го. Как RED и GREEN здесь, он получил
транслятор, написанный на нём самом и воспроизводящий себя байт в байт.

| Каталог | Что там |
|---|---|
| `boot/` | Загрузчик на Python (только для генезиса): он транслирует первый bluec, `genesis/bluec.blu` |
| `bluec/` | bluec, транслятор BLUE, написанный на BLUE (около 9 600 строк); файлы читаются по порядку имён. Выдаёт C для рантайма из `../rt` |
| `seed/bluec.c` | То, во что последний bluec превратил сам себя |
| `tests/` | По программе на каждую возможность языка с ожидаемым выводом; `*.err.blu` должны отвергаться с сообщением из `*.err.out` |
| `corpus/` | 17 программ из документа 1978 года, перепечатанных как в оригинале (`orig/`, с номерами страниц), правки, которых потребовал транслятор (`fix/*.sed`, у каждой указана причина), драйверы (`main/`). `CHANGES.md` перечисляет опечатки |
| `notes/blue-digest.md` | Язык в том виде, в каком он реализован, со ссылками на страницы, и каждое решение там, где документ молчит или противоречит себе |

Самая большая программа корпуса — приложение C, стандартная библиотека
ввода-вывода из документа: SAFE_TELETYPE, TELETYPE, BINARY_IO и TEXTUAL_IO, с
путями-драйверами устройств, привязанными к прерываниям. Она работает на
имитации PDP-11 с двумя телетайпами LT33: первый — консоль, второй тоже печатает
в стандартный вывод.

```sh
make fixpoint        # bluec из семени, дважды; C должен совпасть
make genesis         # первый шаг, от загрузчика на Python
tests/run.sh
corpus/run.sh
```

Нужны компилятор C, make, Python 3 (только для генезиса) и perl (для таймаутов).
Планировщик из `../rt` и его виртуальные часы дают одинаковый вывод при каждом запуске.
