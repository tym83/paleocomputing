# Архитектуры узлов, под которые собирается образ virt-launcher.
#
# Не путать с kubevirt/targets.txt: там — машины, которые эмулируются
# (RISC5), здесь — процессор самого сервера, на котором эмулятор исполняется.
# Эмулятор и libvirt — обычные программы, и под каждый процессор узла их надо
# собрать отдельно. Образ выпуска — многоархитектурный: одно имя, внутри по
# сборке на строку отсюда.
#
# Наш launcher заменяет штатный для ВСЕХ виртуалок кластера. Узел архитектуры,
# которой здесь нет, не запустил бы ни одной — поэтому компонент платформы
# сверяет узлы с этим списком (строка `# arch:` в его таблице) и на таком
# кластере launcher не трогает.
#
# Отсюда читают: launcher.yml, publish.yml, kubevirt-e2e.yml (матрица сборки)
# и marketplace/tools/gen-launcher-table.py (строка `# arch:` таблицы).
#
# Сборка идёт на родном процессоре, без эмуляции: libvirt и QEMU под чужой
# архитектурой через binfmt собирались бы часами.
#
# арх.    раннер GitHub Actions
amd64     ubuntu-latest
arm64     ubuntu-24.04-arm
