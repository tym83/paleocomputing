# Node architectures the virt-launcher image is built for.
#
# Not to be confused with kubevirt/targets.txt: that file lists the machines
# being emulated (RISC5); this one lists the CPU of the server itself, on which
# the emulator runs. The emulator and libvirt are ordinary programs and must be
# built separately for each node CPU. The release image is multi-arch: one
# name, with one build per line from here inside.
#
# Our launcher replaces the stock one for ALL VMs in the cluster. A node of an
# architecture missing here would not start a single one, so the platform
# component checks the nodes against this list (the `# arch:` line in its
# table) and leaves the launcher alone on such a cluster.
#
# Read by: launcher.yml, publish.yml, kubevirt-e2e.yml (build matrix)
# and marketplace/tools/gen-launcher-table.py (the `# arch:` table line).
#
# Builds run on a native CPU, without emulation: libvirt and QEMU built for a
# foreign architecture through binfmt would take hours.
#
# arch    GitHub Actions runner
amd64     ubuntu-latest
arm64     ubuntu-24.04-arm
